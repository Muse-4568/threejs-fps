A round-based tactical FPS in three.js: two teams, short rounds, money and a buy menu between rounds, bots that move, see and shoot back, a bomb to plant and defuse, and gunplay where accuracy counts more than speed.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080.
